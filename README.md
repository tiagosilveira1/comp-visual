# Computação Visual

Este repositório é destinado para projetos envolvendo a disciplina de Computação Visual da FCI (Faculdade de Computação e Informática) Mackenzie (UPM) 2026.

- O código da main desse projeto foi baseado nos códigos dos arquivos fornecidos no repositório do professor.
- [Link do repositório do professor](https://github.com/profkishimoto/CompVis262)
- Código-base utilizado 1: [Link](https://github.com/profkishimoto/CompVis262/blob/main/src/01-hello/main.c). Esse código foi a base para entendermos a configurar nossa máquina e o VSCode para as bibliotecas SDL e SDL_Image. Bem como os links disponibilizados no moodle dos vídeos tutoriais do professor.
- Código-base utilizado 2: [Link](https://github.com/profkishimoto/CompVis262/blob/main/src/03-image/main.c). Esse código foi fundamental para aprendermos e implementarmos o carregamento de imagens, com o patch do arquivo e as diversas funções para validação, renderização e configuração da imagem processada.
