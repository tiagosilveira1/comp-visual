# Computação Visual

Este repositório é destinado para projetos envolvendo a disciplina de Computação Visual da FCI (Faculdade de Computação e Informática) Mackenzie (UPM) 2026.

- O código da main desse projeto foi baseado nos códigos dos arquivos fornecidos no repositório do professor.
- [Link do repositório do professor](https://github.com/profkishimoto/CompVis262)
- Código-base utilizado (escolhido): [Link](https://github.com/profkishimoto/CompVis262/blob/main/src/03-image/main.c). Esse código foi fundamental para aprendermos e implementarmos o carregamento de imagens, com o patch do arquivo e as diversas funções para validação, renderização e configuração da imagem processada. O carregamento de imagens é a etapa inicial da implementação, e, por isso, decidimos partir desse código-base.
